## ❌ IF YOU SEE A DIRECTORY LISTING

Sometimes your browser shows a file/folder list instead. This is a cache issue.

**Quick Fix (Takes 30 seconds):**

### Option A: Use Incognito Mode
```
1. Press: Ctrl + Shift + N
2. Paste: http://127.0.0.1:5000
3. Press: Enter
```

### Option B: Clear Cache
```
1. Press: Ctrl + Shift + Delete
2. Select: "Cached images and files"
3. Click: "Clear data"
4. Refresh page: Ctrl + F5
```

**Then you'll see the real dashboard!**

## 🚨 TROUBLESHOOTING

### Problem: "This site can't be reached"
**Solution:** Server not running. In terminal, run:
```bash
python LAUNCH_APP.py
```

### Problem: See file/folder listing
**Solution:** Browser cache. Press Ctrl+Shift+N for incognito mode

### Problem: Blank page
**Solution:** Hard refresh. Press Ctrl+F5

### Problem: Port error
**Solution:** Port 5000 in use. Kill process or use different port
