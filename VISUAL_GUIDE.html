🚨 Troubleshooting: If You See Directory Listing

Problem: Browser shows file/folder list instead of dashboard

Cause: Browser cache showing old static folder index

Solution 1: Clear Browser Cache
Press: Ctrl + Shift + Delete
Select: "Cached images and files"
Time Range: "All time"
Click: "Clear data"
Refresh: Ctrl + F5
Solution 2: Use Incognito/Private Mode
Press: Ctrl + Shift + N (Chrome/Edge)
Or: Ctrl + Shift + P (Firefox)
Navigate to: http://127.0.0.1:5000
Solution 3: Verify URL
✅ Correct: http://127.0.0.1:5000
✅ Correct: http://localhost:5000
❌ Wrong: file:///C:/Revenue%20intelligence...
❌ Wrong: http://127.0.0.1:5000/static/
